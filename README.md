# PDFTturn / PDF旋轉吧

PDFTturn V1.7 是以 Python tkinter 製作的 PDF 工具，提供頁面旋轉、壓縮、合併與頁面編輯功能。

## 檔案

- `outputs/PDFTturn_V1.7_PDF旋轉吧.py`：主程式
- `outputs/PDFTturn_V1.7_PDF旋轉吧.pyw`：Windows 雙擊執行版本
- `outputs/PDFTturn_V1.7_使用說明.md`：使用說明

## 執行

```bash
python outputs/PDFTturn_V1.7_PDF旋轉吧.py
```

Windows 可雙擊 `.pyw` 檔執行。
